# Android

Нативное приложение: Kotlin + Jetpack Compose, Material 3, OkHttp +
kotlinx.serialization, Coil. Работает поверх JSON API из корня репозитория.

```
ru.teivrim.anime
├── AnimeApp.kt        контейнер зависимостей
├── MainActivity.kt     точка входа и навигация
├── data/               модели, HTTP-клиент, репозиторий, настройки
└── ui/                 строки, тема, экраны, компоненты
```

---

## Сборка

Нужны JDK 17+ и Android SDK (compileSdk 36).

Версии инструментов зафиксированы осознанно: AGP 8.13 + Gradle 8.13 + Kotlin
2.2.10. AGP 9.x не подходит — он регистрирует собственное расширение `kotlin`, и
наложение `org.jetbrains.kotlin.android` падает с «Cannot add extension with name
'kotlin'». Взамен у AndroidX есть версии новее (core-ktx 1.19, lifecycle 2.11),
но они требуют compileSdk 37 и AGP 9.1, то есть упираются в то же ограничение.
Поэтому в `app/build.gradle.kts` закреплены максимально свежие версии,
совместимые с AGP 8.13: `core-ktx 1.16.0` и `lifecycle 2.9.4`. Поднимать их
можно только вместе с обновлением AGP.

```bash
cd android

# Отладочная сборка ставится на эмулятор и сразу видит локальный сервер:
# 10.0.2.2 — это адрес хост-машины глазами эмулятора.
./gradlew :app:assembleDebug

# Релизный AAB для RuStore
./gradlew :app:bundleRelease

# Релизный APK (для ручной установки)
./gradlew :app:assembleRelease
```

### Windows

Gradle и `java` не всегда в `PATH`:

```powershell
$env:JAVA_HOME = "D:\123\jbr"                 # или путь к вашему JDK
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
.\gradlew.bat :app:assembleDebug
```

`android/local.properties` создаётся при первом запуске Android Studio и
указывает путь к SDK. Он в `.gitignore`.

## Подпись

Релизная сборка подписывается ключом из `android/keystores/`. Создать:

```powershell
powershell -File ..\tools\make-keystore.ps1
```

Скрипт спрашивает пароль и пишет:

- `android/keystores/anime-release.jks` — сам ключ
- `android/keystores/keystore.properties` — путь, пароли, alias и `apiBaseUrl`

Оба файла в `.gitignore`. **Потерянный ключ = нельзя выпустить обновление
существующего приложения в RuStore.** Сделайте копию отдельно от репозитория.

Без `keystore.properties` сборка всё равно работает и выдаёт **неподписанный**
артефакт, так что конфигурация не падает на свежем клоне.

`apiBaseUrl` в этом же файле задаёт адрес сервера для релизной сборки. Для
локальной разработки дефолт — `http://10.0.2.2:8082/` (эмулятор → хост).
Прод должен быть `https://`, иначе `usesCleartextTraffic=false` его заблокирует.

## Разрешения

Приложение просит только `INTERNET` и `ACCESS_NETWORK_STATE`. Камера,
микрофон, геолокация и хранилище не нужны — RuStore снижает оценку за лишние
разрешения.

Cleartext-трафик запрещён глобально, кроме `10.0.2.2` / `localhost` для отладки
(`res/xml/network_security_config.xml`).

## Публикация в RuStore

Подготовка целиком описана в [`docs/RUSTORE.md`](../docs/RUSTORE.md):
метаданные, скриншоты, описание, загрузка AAB.

Коротко:

```powershell
# Сухая проверка: покажет, что уйдёт на сервер, ничего не отправляя
powershell -File ..\tools\rustore-upload.ps1 `
    -FilePath app\build\outputs\bundle\release\app-release.aab -WhatIf
```

`versionCode` берётся из AAB, то есть из `defaultConfig.versionCode`.
Загрузка и отправка на модерацию — разные шаги; второе включается `-Commit`.

## Архитектурные заметки

**Зависимости.** Контейнер собирается вручную в `AnimeApp`. Граф состоит из
трёх объектов; Hilt добавил бы annotation processor, время сборки и размер APK
ради ничего.

**Сеть.** OkHttp + kotlinx.serialization, без Retrofit: поверхность — это
 десяток эндпоинтов с одним и тем же query-форматом, а OkHttp всё равно нужен для
пула соединений. Обёртка отличила сетевую ошибку, 401, 429 и 5xx, потому что на
каждый нужен свой отклик в интерфейсе.

**PATCH-семантика.** `POST /api/favorites` различает «поле отсутствует»
(оставить как есть) и «поле равно `null`» (очистить). Поэтому кодировщик запросов
намеренно пишет `null`, а читатель — нет: без явного `null` сервер сохранил бы
старую оценку вместо очищенной.

**Навигация.** Каталог, список и настройки живут под нижней панелью; детальная
страница и вход открываются поверх вкладки, и панель на них скрыта. Переключение
вкладок использует `saveState`/`restoreState`, поэтому возвращение в каталог
сохраняет позицию прокрутки.

**Обложки.** Все URL картинок идут через прокси на сервере
(`/api/img?u=`). Один кэшируемый адрес вместо зависимости от чужих CDN, плюс
allow-list хостов и заглушка, если картинки нет.

**Сессия.** Токен хранится в DataStore и дублируется в поле в памяти: OkHttp
interceptor читает его синхронно на каждом запросе, и читать DataStore оттуда
значило бы блокировать сетевой поток. При 401 interceptor сбрасывает токен —
отозванная и истёкшая сессия неотличимы, и обе означают одно и то же.

**Обновление состояния.** Избранное переключается оптимистично: звезда должна
реагировать сразу, иначе на медленной сети список кажется сломанным. При
ошибке состояние откатывается.
